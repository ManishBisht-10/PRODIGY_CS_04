# PRODIGY_CS_04 — Keystroke Logger

Small project demonstrating a simple keystroke logger (for educational/testing purposes only).

Contents
- `keystroke_logger.py`: main logger implementation
- `keystrokes.txt`: sample/output file written by the logger
- `test_keystroke_logger.py`: unit tests for the logger

Requirements
- Python 3.8+
- (Optional) `pytest` to run tests

Usage
1. Run the logger (may require admin privileges on some platforms):

```bash
python keystroke_logger.py
```

2. Inspect `keystrokes.txt` for captured output.

Running tests

```bash
pip install -r requirements.txt  # optional; or pip install pytest
pytest -q
```

Notes
- This repository is for learning and testing only. Do not use keystroke loggers on machines or accounts without explicit permission.
